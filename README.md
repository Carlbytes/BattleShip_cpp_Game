## 📜 Project Overview
A multiplayer, turn-based Battleship game built in C++ using the SFML library for networking. Features a Client-Server architecture, OOP design principles, and a professional installer.

## ✨ Key Features
* **Multiplayer Networking:** TCP/IP socket connection for LAN/WAN play.
* **OOP Design:** Utilizes Inheritance, Polymorphism, and the Singleton Design Pattern.
* **Game Mechanics:** Cursor-based aiming, ship placement, and hit/miss tracking.
* **Installer:** Packaged with Inno Setup for easy deployment.

## 🛠️ Tech Stack
* **Language:** C++
* **Library:** SFML (Simple and Fast Multimedia Library)
* **IDE:** Visual Studio 2022
* **Testing:** Microsoft Native Unit Test Framework

## 🚀 How to Run
1.  Download the latest installer from the [Releases] tab.
2.  Run `Battleship_Setup.exe`.
3.  Launch the game from your Desktop shortcut.
